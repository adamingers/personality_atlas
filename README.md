# Personality Semantic Atlas

An interactive map of **779 personality trait-profiles** drawn from **77 systems** and **66 theorists and traditions** — from Theophrastus to HEXACO, the Chinese zodiac to phrenology — positioned by the adjectives each profile actually uses rather than by who wrote it.

**Live site:** https://adamshiva.com/personality_atlas/

## The two maps

| | |
|---|---|
| **[Cooked](cooked.html)** | The traits arranged into six designed family squares (four classical humors + Competence + Mystical) with deliberate axes and transition bands. The frame is imposed; positions within it are earned from the data. |
| **[Harvested](harvested.html)** | The same traits with no imposed structure. Profiles are embedded (PPMI → 120-d SVD) and projected to 2-D with UMAP, so distance means dissimilarity. Communities, axis words and valley lines are all derived. |

Both maps support full trait profiles, side-by-side comparison of traits or lassoed regions, adjective harvesting by region, semantic word links, cross-system convergence colouring, and a lock for tracing lines without losing your place.

## Repository layout

```
CNAME                          repo ROOT — custom domain; must stay at the root
.nojekyll                      repo ROOT
personality_atlas/
  index.html                   landing page — entry point to both maps
  cooked.html                  the designed map    (self-contained, no dependencies)
  harvested.html               the derived map     (self-contained, no dependencies)
  masters/                     the two source-of-truth JSON data files
  build_tools/                 parsers, ingest pipeline, injector, test suite
  docs/                        handoff and audit documents
```

Everything inside `personality_atlas/` uses **relative links only**, so the folder can be moved or renamed without breaking anything.

The two charts are single-file and zero-dependency: each contains its own data, styles and code, and will open from a local file with no server.

## Rebuilding

Data lives in `masters/`. The charts are generated by re-embedding those masters into the chart shells and injecting the feature layer — see `docs/ATLAS_HANDOFF_v4.md` for the full pipeline, the embedding recipe, and the schema notes.

## A note on what this is

The systems mapped here are not equally credible. Phrenology and the zodiac are included as historical objects — things people believed about character — alongside instruments with real psychometric standing. Placing them on one map is a claim about vocabulary, not validity. Where independent traditions land in the same place, that convergence is worth noticing; it is not by itself evidence that any of them is true.
